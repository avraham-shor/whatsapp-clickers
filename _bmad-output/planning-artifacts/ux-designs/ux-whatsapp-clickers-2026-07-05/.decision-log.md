## Batched Assumptions (fast path — tagged inline in the spines)

**All assumptions A1–A14 confirmed by the user, 2026-07-09 ("מעולה"). Inline `[ASSUMPTION]` tags remain as provenance markers — they record derived-not-dictated choices, not open items.**

- **A1 — Emoji policy:** symbolic set only (🎉 🏆 ⚡ ✓); max one per message except winner/final-results; no face/person emoji (filter-safe conservatism).
- **A2 — Gender-neutral Hebrew:** past-2nd-singular spellings that read for both genders (נרשמת, ענית, זכית, סיימת), impersonal constructions, plural imperatives for instructions (השיבו, שלחו). No "ברוך הבא".
- **A3 — OQ-3 resolved:** display name = WhatsApp profile name; correctable any time by replying `שם: <השם>`; confirmation reply sent.
- **A4 — OQ-5 resolved:** organizer disconnect sends **no** WhatsApp message; the Audience Display carries the reconnect state; room-level problems are solved in the room.
- **A5 — Wrong-answer result** includes the correct answer + a short encouraging line (not on the last question).
- **A6 — Ack copy:** "התקבל ✓ — בהצלחה!" (contains the PRD-mandated "התקבל ✓").
- **A7 — Matched validation stage** (exact/fuzzy/AI) is not shown to Participants — organizer-side only.
- **A8 — Default per-question time limit: 20s** (matches PRD FR-4 example).
- **A9 — Audience Display:** designed at 1920×1080 (16:9), minimum 1280×720; type ramp at 1080p — timer numeral 96px, question 64px, options 40px, leaderboard 40px; split-hero band 30–35% of stage height.
- **A10 — Reveal distribution:** horizontal bars per option, animate ~400ms on entry; static under reduced-motion.
- **A11 — Leaderboard stage:** top-10 depth; movement indicators (▲ + places climbed); no current-user pinning — it's a shared screen.
- **A12 — Stage fullscreen** via browser fullscreen (F11); no kiosk mode or pairing flow.
- **A13 — Question Bank browse:** package cards with question-count + preview; imported questions get an editable "מהמאגר" badge; copies per FR-12.
- **A14 — Marketing site** removed from the pilot spine (commercial phase, PRD §6.2).
